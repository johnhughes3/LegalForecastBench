# Exploratory comparisons

Dated, one-off analyses supporting public numerical claims live here, separately from the working papers and website. Each directory keeps the minimal source inputs, a reproduction command, the calculated results, and the relevant methodological limits. These are exploratory analyses, not additions to the benchmark protocol.

Add later comparisons under `YYYY-MM-DD-topic/` and link them below. Preserve the inputs used for a claim rather than silently refreshing them from a changing leaderboard. Keep the associated social posts and discussion in the pull request description.

- [2026-11-11: AA Intelligence Index and Harvey LAB-AA](2026-11-11-aa-lab-aa/README.md): the cited effort-matched and model-matched correlations, older-model comparison, Brier references, and cohort counts.
