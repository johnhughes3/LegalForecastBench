## Definite defect

- **C-032 imposes an unsupported procedural disclaimer for contention interrogatories.** It fails a request for facts supporting an affirmative defense unless it cites Rule 33(a)(2), expressly mentions judicial deferral, or meets a different factual framing. Rule 33(a)(2) affirmatively permits fact/law-to-fact contentions and allows the court to defer them; it does not require the serving party to recite that discretion. Scheduling order P24–27 sets subpart limits, deadline, and proportionality but imposes no such disclaimer. A targeted, proportionate request for facts supporting an identified defense is not defective merely for omitting a deferral reminder. [Rule 33(a)(2)](https://www.law.cornell.edu/rules/frcp/rule_33). Repair: score substance, scope, timing and actual orders, not magic words.

## Arguable/format concerns

- **C-007–010/C-015 require named Definitions-section boilerplate.** Prompt asks a first set of interrogatories and a filename; it does not mandate a separate definition of everyday “Describe.” Clear self-contained questions or equivalent integrated definitions may be equally effective. C-015 particularly fails solely because a definition is not in a designated section. Repair: assess unambiguous scope and necessary definitions wherever stated.
- **C-019's gloss can overcount.** Scheduling order P25 expressly uses logical/factual relationship and a natural-component standard. Rubric's “different categories of information” must not override that source. Rule 33's 1993 note treats a communication's time/place/persons/contents as one inquiry, not automatically separate subparts. Use the order's actual relatedness standard. This is an ambiguity, not proof any particular 25-question draft complies.
- **C-026/C-048 minor internal tension.** C-026 permits a generic device description or broad CMT-file inquiry; C-048 can fail an otherwise precise device request solely for omitting CX-8827491. The number is source-supported (complaint P188 and forensic materials), but equivalent unambiguous identification should pass.
- **C-016 supplementation wording is broader than Rule 26(e).** A duty arises when response is materially incomplete/incorrect and corrective information has not otherwise been made known; not every newly available datum automatically demands supplementation. Accurate qualified Rule 26(e) instructions should pass. [Rule 26(e)](https://www.law.cornell.edu/rules/frcp/rule_26).
