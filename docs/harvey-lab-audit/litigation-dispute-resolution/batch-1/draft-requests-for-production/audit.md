## Definite rubric defect

- **C-038 conflicts with an express source instruction.** Rubric mandates referencing the protective order and designation levels. Partner strategy memo P25–26 expressly says Alicia does not need to address protective-order designations in the RFPs. The prompt asks drafting based on attached strategy memos. A draft following that explicit permission to omit designations should not fail. Repair: make the reference optional, or assess compliance with the order without requiring recitation.
- **C-040 inconsistent pass/fail threshold.** PASS requires every numbered request to contain a limiting feature; FAIL requires three or more unbounded requests. One or two unbounded requests are undefined. Repair consistent threshold tied to proportionality.
- **C-050 inconsistent conjunctive requirements.** PASS requires custodians and date ranges; FAIL triggers when both are absent. A draft omitting only one can fall between branches despite CMO P44 requiring both. Repair an explicit rule that either omission fails, with reasonable global definitions allowed.

## Arguable concerns / checks that did not establish defects

- **C-024 litigation-hold notices need privilege care.** Partner memo P44–51 requests this topic and distinguishes nonprivileged communications; thus the category is supported. But the notices' content may be privileged, so a draft requesting nonprivileged hold facts, dates, scope, recipients and implementation evidence should not fail solely for avoiding demand for counsel's privileged text. [Rule 26(b)(1), (b)(3), (b)(5)](https://www.law.cornell.edu/rules/frcp/rule_26). No categorical assertion that all hold notices are privileged or all are discoverable is warranted.
- **C-043 demands re-requesting EDA.** Partner memo P56 warns against cumulative material already available to Blackthorn; however requesting defendant's executed version and amendments is defensible. Treat omission of the already-possessed original as arguable tactical discretion where all modifications/side agreements are sought, not a definite legal defect.
- **C-033–034 native production is supported, not hidden.** Partner memo P22–24 explicitly requests native metadata-sensitive material; protective order §§8.2–8.3 permits category-specific requests, while CMO P48–49 defaults to TIFF with metadata. A blanket unilateral demand cannot override the order's objection/meet-and-confer mechanism, but the rubric allows the narrower valid form.
- **Prompt says ready for filing.** Federal Rule 5(d)(1)(A) generally keeps discovery requests off the docket until used or ordered filed. This is a prompt imprecision, not a rubric defect, and producing a service-ready draft with caption/certificate is a sensible interpretation. [Rule 5](https://www.law.cornell.edu/rules/frcp/rule_5).
