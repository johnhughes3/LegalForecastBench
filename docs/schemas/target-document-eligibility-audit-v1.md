# Target-document eligibility audit v1

`legalforecast.target_document_eligibility_audit.v1` is the provider-free semantic preflight for the line-addressed `claim-ontology-v4` and `claim-ontology-v5` Stage A unitizer contracts. It is derived deterministically from the exact authenticated selection bytes, canonical parser manifest, and complete authenticated Markdown snapshot before registry, cap, journal, or provider authority is opened.

The JSONL contains one record for each selected target-motion notice or memorandum, in selection and document order. Each record binds the candidate, source document, document role, exact Markdown SHA-256, and one closed status: `eligible` or `stipulated_ineligible`. Missing target documents, incomplete parser coverage, parser/Markdown hash drift, duplicate identities, noncanonical bytes, unknown fields, or any other status fail closed.

Persisted audit bytes are an integrity surface, not authority. The completed `audit-stage-a-target-eligibility` run card commits the full provider-free parse lineage, audit hash, artifact paths, and explicit false authority flags for providers, retrieval, PACER, RECAP Fetch, evaluation, freeze, and dispatch. Its closed `replay_paths` mapping records the `controlled_private_root` and `purchase_ledger_initialization_receipt` paths (each a path or `null`) needed to reconstruct the exact materialization context; these values are revalidated by the materialization verifier and are never authority on their own. The line-addressed v4 and v5 contracts replay both the audit and run card from the same authenticated source bytes and stop if any record is ineligible. Only the current v5 contract is admitted to executed `acquisition llm-unitize`; v4 and the older v2/v3 contracts remain available for dry runs, provider-free replay, and explicit reconstruction recovery without being reinterpreted. The exact-100 successor may similarly replay a completed audit root only when the reconstructed selection bytes equal its sealed predecessor and exactly one target is ineligible.
