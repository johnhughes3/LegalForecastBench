# Successor rerun proposal and impact v1

`legalforecast.successor_rerun_proposal.v1` is a closed, non-authoritative input envelope for comparing a proposed Stage A successor with one authenticated predecessor. Its exact field set is `schema_version`, `cycle_id`, `selection_path`, `selection_sha256`, `selection_run_card_path`, `selection_run_card_sha256`, `download_manifest_path`, `download_manifest_sha256`, `disclosure_clearance_path`, `disclosure_clearance_sha256`, `materialization_run_card_path`, `materialization_run_card_sha256`, `document_root`, `model_registry_path`, `model_registry_sha256`, `policy_path`, `policy_sha256`, `provider_attempt_namespace`, `model_key`, `successor_output_root`, and `non_authoritative`. Unknown or missing fields fail closed. Every committed file path is absolute and paired with the lowercase SHA-256 of its exact bytes; input digest fields accept either bare lowercase hexadecimal or the same value prefixed by `sha256:` and normalize it to bare hexadecimal for comparison. `document_root` and `successor_output_root` are path constraints rather than authority. `successor_output_root` is an absolute alias: its parent must resolve to an existing directory, and the canonical resolved root is the path exposed in reports and commands. That canonical root must be new and disjoint from every authenticated input. The alias is resolved again after planning, before acceptance, so parent-symlink retargeting or any other alias change fails closed.

Proposal bytes use `legalforecast.codec.artifact-canonical-json.v1`: UTF-8 JSON with sorted keys, compact separators, non-ASCII text preserved, non-finite numbers rejected, and one trailing newline. `proposal_sha256` in a report is the lowercase SHA-256 of those complete canonical proposal bytes. The CLI separately replays the selection, materialization, registry, policy, parser, provider-journal, and active-lineage evidence; a syntactically valid proposal does not authenticate itself.

`legalforecast.successor_rerun_impact.v1` is the deterministic advisory result. A successful report has the closed top-level field set `schema_version`, `advisory`, `authority`, `warning`, `cycle_id`, `proposal_sha256`, `proposed_global_commitments`, `first_invalidated_stage`, `stages`, `affected_cases`, `affected_candidates`, `affected_documents`, `reusable_documents`, `reusable_parser_outputs`, `reusable_exact_byte_output_count`, `reusable_logical_calls`, `provider_logical_call_gaps`, and `next_commands`. A failed report omits `cycle_id`, `proposal_sha256`, and `proposed_global_commitments`; it retains every other field with `lineage` marked `FAILED`, descendants marked `NOT_EVALUATED`, empty result collections, and no next commands. Stage records are closed by status: successful records contain only `stage` and `status`; `FAILED` adds `diagnostics`; `NOT_EVALUATED` adds `blocked_by`. Each diagnostic contains exactly `code` and `message`. The fixed authority mapping contains exactly `artifact`, `dispatch`, `execution`, `freeze`, `provider`, `publication`, and `purchase`, all `false`.

The remaining nested records are also closed. `proposed_global_commitments` contains exactly `model_key`, `model_provider`, `model_registry_sha256`, `policy_sha256`, `provider_account`, and `provider_attempt_namespace`. A reusable parser output contains exactly `candidate_id`, `source_document_id`, `markdown_sha256`, and `parser_reuse_identity_sha256`. The parser reuse identity is the raw lowercase digest from the named `legalforecast.commitment.artifact-canonical-json.raw-sha256.v1` profile, domain-separated by `legalforecast.successor_rerun_impact.v1`, over an artifact-canonical JSON object containing exactly `source_key`, `markdown_path`, `metadata_path`, `record_sha256`, `markdown_sha256`, `metadata_sha256`, and `output_markdown_sha256`; its hashed bytes include the profile codec's single trailing newline. A reusable logical call contains exactly `candidate_id`, `logical_call_key`, and `attempt_ordinal`. A provider logical-call gap contains exactly `candidate_id` and `reason`. An ordinary next-command record contains exactly `stage`, `argv`, `execution_authority`, and `requires_separate_authorization`; the `llm-unitize` variant additionally contains `advisory_execution`.

JSON rendering is byte-deterministic: sorted keys, compact separators, UTF-8 text, and one trailing newline. Text rendering is likewise deterministic and begins with the advisory warning. A report is successful only when its advisory marker is true and every stage has status `REUSABLE` or `AFFECTED`; `FAILED` and `NOT_EVALUATED` are never successful states.

Both schemas are observational. They grant no execution, provider, purchase, freeze, dispatch, publication, artifact, receipt, ledger, or provider-response authority, and the planner performs none of those operations. A rendered next command is derived from authenticated inputs, never supplied by the proposal. Each command records `execution_authority: false` and `requires_separate_authorization: true`; commands that include `--execute` still require the operator's separate existing authority, while `llm-unitize` is rendered without `--execute` as a dry-run-only advisory. Exact commands are valid only while every referenced authenticated byte and active-lineage identity remains unchanged.

When only model, provider, account, provider-attempt namespace, registry, or policy identity changes, parser work remains reusable. The recommendation therefore references the complete already authenticated predecessor selection, materialization, parse-request, parser-manifest, parser-run-card, document-root, and Markdown-root lineage rather than mixing path-bound receipts with equivalent proposal paths. A current line-addressed `claim-ontology-v4` or `claim-ontology-v5` eligibility audit is reused only after semantic replay against that lineage; an upgrade from an older namespace first recommends a new provider-free eligibility audit. Policy drift omits the old caps-bound provider journal so later separately authorized execution uses a new journal under the successor root. No recommendation points at a parser artifact that does not exist.
