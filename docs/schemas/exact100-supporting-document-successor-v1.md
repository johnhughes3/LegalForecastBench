# Exact-100 supporting-document successor v1

`legalforecast.exact100_supporting_document_successor.v1` is the closed, zero-cost successor for one missing public supporting memorandum in the otherwise authenticated exact-100 v2 cohort.

It preserves the exact 100 selected candidates, replays the completed exact-100 v2 successor, and rederives `legalforecast.free_support_memorandum_recovery_plan.v1` from the authenticated raw-docket bridge. It may add only candidate `73327542`, ECF 14, document ID `73327542-entry-14-motion-to-dismiss-memorandum`, with role `motion_to_dismiss_memorandum`, and only from the canonical plan-derived CourtListener storage URL.

The successor emits a complete replacement target projection: selection, case relevance, merged manifest, clearance, restriction evidence, and core-filter output. It also emits an immutable supplemental free source tree. The supplemental tree contains the one downloaded memorandum and the already-authenticated promoted-candidate free documents needed to preserve the materializer's existing `free/free/purchased` source layout.

The successor's single state/config run card is this new schema, not `legalforecast.acquisition_run_card.v1`. It commits the exact v2 root, recovery plan, raw-docket bridge, the supplemental source manifest and clearance, and every emitted projection artifact. The pre-existing materializer continues to receive its normal target-root input and retains its existing 15-input `legalforecast.acquisition_run_card.v1` shape; no conditional fields or input paths are added to that card.

All output directories are opened with no-follow file descriptors. A symlinked root, a symlinked output component, overlap with any immutable input, an unexpected existing file, or a post-write identity change fails before or during publication. The command has no PACER, RECAP Fetch, paid-provider, model-provider, evaluation, freeze, or dispatch authority.
