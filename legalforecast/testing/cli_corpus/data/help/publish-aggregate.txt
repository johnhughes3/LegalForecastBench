usage: legalforecast [-h] --per-case-dir PER_CASE_DIR
                     --run-input-manifest RUN_INPUT_MANIFEST --labels LABELS
                     --output-dir OUTPUT_DIR --cycle-id CYCLE_ID
                     --cycle-series {pilot,rapid,official,annual_aggregate}
                     --clean-motion-count CLEAN_MOTION_COUNT
                     --prediction-unit-count PREDICTION_UNIT_COUNT
                     [--model-key MODEL_KEY] [--model-registry MODEL_REGISTRY]
                     [--baseline-training-examples BASELINE_TRAINING_EXAMPLES]
                     [--allow-incomplete-model-set] [--supplementary]
                     [--allow-no-baselines]
                     [--deferred-ablation DEFERRED_ABLATION]
                     [--elapsed-days ELAPSED_DAYS]
                     [--official-window-days OFFICIAL_WINDOW_DAYS]
                     [--paired-delta-sd PAIRED_DELTA_SD]
                     [--target-mde TARGET_MDE] [--target-power TARGET_POWER]
                     [--two-sided-alpha TWO_SIDED_ALPHA] [--ablation ABLATION]
                     [--title TITLE] [--base-rate BASE_RATE]

Aggregate official per-case outputs into a public-safe bundle.

options:
  -h, --help            show this help message and exit
  --per-case-dir PER_CASE_DIR
  --run-input-manifest RUN_INPUT_MANIFEST
  --labels LABELS
  --output-dir OUTPUT_DIR
  --cycle-id CYCLE_ID
  --cycle-series {pilot,rapid,official,annual_aggregate}
                        Cycle cadence used for claim-strength classification.
  --clean-motion-count CLEAN_MOTION_COUNT
  --prediction-unit-count PREDICTION_UNIT_COUNT
  --model-key MODEL_KEY
                        Expected registry key in provider:model_id form.
                        Repeat for a multi-model matrix.
  --model-registry MODEL_REGISTRY
                        Frozen model registry JSON. When --model-key is
                        omitted, every registry entry is treated as an
                        expected model output.
  --baseline-training-examples BASELINE_TRAINING_EXAMPLES
                        JSONL or JSON historical baseline corpus. When
                        provided, global, court/NOS/motion, metadata-only, and
                        judge-history baselines are scored as deterministic
                        pseudo-model rows.
  --allow-incomplete-model-set
                        Permit aggregation without a registry or explicit
                        expected model keys. Intended only for partial/debug
                        bundles and recorded in the run card.
  --supplementary       Aggregate a supplementary bundle of models released
                        after the corpus decision window closed. Every model
                        in the registry must classify as supplementary; an
                        official model here is refused, as is a supplementary
                        model in an official bundle.
  --allow-no-baselines  Permit aggregation without baseline-training examples.
                        Intended only for partial/debug or explicitly
                        disclosed first-cycle bundles and recorded in the run
                        card.
  --deferred-ablation DEFERRED_ABLATION
                        A planned ablation intentionally deferred from this
                        cycle, recorded in the run card for publication
                        disclosure.
  --elapsed-days ELAPSED_DAYS
  --official-window-days OFFICIAL_WINDOW_DAYS
  --paired-delta-sd PAIRED_DELTA_SD
                        Override the paired delta standard deviation used for
                        MDE analysis. When omitted, aggregation derives it
                        from observed bootstrap deltas or repeat-variance
                        summaries before falling back to the documented
                        default 0.05.
  --target-mde TARGET_MDE
                        Target minimum detectable effect for cycle-power
                        analysis.
  --target-power TARGET_POWER
                        Target statistical power for cycle-power analysis.
  --two-sided-alpha TWO_SIDED_ALPHA
                        Two-sided alpha for cycle-power analysis.
  --ablation ABLATION
  --title TITLE
  --base-rate BASE_RATE
